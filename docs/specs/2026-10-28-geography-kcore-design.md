## 2. New results (paper Section "Proposed Model")

Notation: `s = 1 - phi`, `S_k(N,p) = P[Bin(N,p) >= k]`, `G(u) = [S_k(n, x u)]^m`. A refinement `c -> c'`
means `c | c'` (each cluster is split into equal sub-clusters).

**Theorem 1 (abrupt iff k·m >= 2). Replaces and strengthens Property 1.** Let `n >= max(k,2)`, `phi < 1`, and `c | n`.
The collapse of `r*` as `x` (or `phi`) varies is discontinuous **iff** `k·m >= 2`.
*Proof.* (<=) A union bound gives `S_k(N,p) <= C(n,k) p^k`, so `F(r) <= C r^{km} <= C r^2` uniformly in `x` and `phi`.
Hence there is an `eps > 0` with `F(r) < r` on `(0, eps]`, so any positive fixed point is at least `eps`. Since `r*` is
monotone in the parameter, and 0 at one end but positive at the other, it jumps by at least `eps`.
(=>) If `k = m = 1`, then `F(r) = E[1 - (1 - x r)^B]` is concave with `F'(0) = x n s`. This is a Galton–Watson
process, so `r*` rises continuously from 0 at `x n s = 1`.
*Generalizes:* EGL Prop. 1 (`m >= 2`, `k = 1`) and Arjun's Property 1 (`k >= 2`, one direction only).
*DGM link:* our `k` corresponds to DGM core index `K = k + 1`. With `m = 1` and `c = n`, writing `u = s r` gives
`u = s S_k(n, x u)`, which has the same form as DGM's ER equation `u = p P[Poisson(z u) >= K - 1]`.
So `k = 1` corresponds to the 2-core (ordinary percolation, continuous), and `k >= 2` to the `K >= 3` cores (hybrid).

**Theorem 2 (closed form for the two extremes). New.** Let `a* = 1 / sup_{u in (0,1]} G(u)/u`. Then
`phi*_spread = 1 - a* = 1 - x_crit/x` (Arjun's Property 2) and
`phi*_colocated = 1 - (a*)^{1/m} = 1 - (1 - phi*_spread)^{1/m} = 1 - (x_crit/x)^{1/m}`.
*Proof.* For `c = n`, `r = G(s r)`; substituting `u = s r` gives `u = s G(u)`. For `c = 1`, `r = s^m G(r)`.
A positive fixed point of `u = a G(u)` exists iff `a >= a*`, which gives both formulas.
*Corollaries:* (i) when `m = 1` the two thresholds are **identical**, while reliability differs by the factor `1/s`;
(ii) when `m >= 2`, `phi*_colocated ≈ phi*_spread / m`, so correlation hurts through complexity;
(iii) it reproduces Arjun's Table 1 (0.0766 -> 0.0391; 0.4249 -> 0.2417).

**Theorem 3 (k = 1: spreading never hurts). Proves the conjecture for k = 1.** If `k = 1` and `c | c'`, then
`F_c(r) <= F_{c'}(r)` for all `r`, so `r*_c <= r*_{c'}` and `phi*_c <= phi*_{c'}`.
*Proof.* The per-input success probability is `E[h(B_c)]`, where `h(N) = 1 - (1-p)^N` is concave in `N`, and
`B_c = b · Bin(c, s)`. Within each cluster, `b·Bern(s)` is the comonotonic sum of `b/b'` copies of `b'·Bern(s)`.
A comonotonic sum dominates in convex order (Dhaene et al. 2002), and convex order is preserved under
independent convolution, so `B_c >=_cx B_{c'}` and `E h(B_c) <= E h(B_{c'})`. `F` is increasing in that quantity,
and the largest fixed point is monotone in `F`.

**Proposition 4 (diversification trap for k >= 2). Refutes the conjecture.** For `k >= 2`, `h_k(N) = S_k(N,p)` is
convex for small `N`: its increments `p · P[Bin(N,p) = k-1]` rise at first. So clustering can help, and an
*intermediate* `c` can be strictly worse than both extremes.
Counterexample: `n=4, k=2, m=1, x=0.9`, with `phi*(c=1) = phi*(c=4) = 0.1946 > phi*(c=2) = 0.1705`.
With two inputs: `n=6, k=3, m=2, x=0.95`, with `phi*(c=2) = 0.0699 < phi*(c=1) = 0.0781`.
Numerical map: in 360 cases (`n ∈ {2,4,6,8}`, `k ∈ 1..n`, `m ∈ {1,2,3}`, `x ∈ {.6,.7,.8,.9,.95,1}`), refinement
monotonicity fails in 79, all with `k >= 2`, and in none of the 48 `k = 1` cases.
*Mechanism:* losing one of two clusters leaves exactly `k` suppliers, so firms become "barely sourced" (DGM's corona).
*Interpretation (stated as a model result):* splitting supply across two regions, a common resilience
recommendation, can be the worst arrangement for buyers that need several suppliers per input.
Theorem 2 implies that the extremes are always ordered (`phi*_colocated <= phi*_spread`), so the trap is interior.

## 3. Experiments

All experiments reuse `simulate.py` unchanged and follow E3's method: estimate the realized-shock split point
for `rho < 0.1`, with 500 bootstrap replicates.

- **E5 (trap and closed form on finite networks).** `x = 0.9`; configurations `(m,n,k) ∈ {(1,4,2), (1,6,3),
  (2,6,3), (3,4,2)}` over all `c | n`. For each, 9 `phi` values in `[0.6, 1.4]·phi*_D20` with 30 replications (~3,800 runs,
  ~12 min on 2 cores). Report simulated `phi*` with CI next to deep and depth-20 theory. Pass criteria: simulation
  within the CI of depth-20 theory in at least 90% of rows; the trap ordering `phi*(c=2) < min(phi*(1), phi*(n))` holds
  in the CIs for `(1,4,2)` and `(1,6,3)`. Expected depth-20 theory: `(1,4,2)`: 0.217 / 0.195 / 0.216;
  `(1,6,3)`: 0.201 / 0.150 / 0.167 / 0.201.
- **E6 (DGM reproduction).** Erdős–Rényi graphs, `N = 100,000`, mean degree 10. Remove a fraction `Q` of vertices
  (grid bracketing each `Q_c(k)`, `k = 2..7`, two replications), and compute k-cores with a new NumPy peeling routine
  (`code/kcore.py`, no networkx dependency). Pass: each theoretical `Q_c(k)` lies inside the simulated bracket; the 7-core
  threshold is about 1.25%. The paper uses one sentence for this result.
- **Existing E1–E4** are kept as they are. The paper text compresses E1 and E4a.
