**Interfaces:**
- Produces:
  - `phi_star_closed_form(x: float, m: int, n: int, k: int) -> dict` with keys `"spread"` and `"colocated"` (floats, ≥ 0), from `xc = x_crit(m,n,k)`: spread = max(0, 1 − xc/x); colocated = max(0, 1 − (xc/x)**(1/m)).
  - `refinement_violations(x: float, m: int, n: int, k: int, tol: float = 1e-4) -> list[tuple[int, int, float, float]]`: all `(c, c2, phi_c, phi_c2)` with `c | c2`, `c < c2`, `c2 | n`, and `phi_star(c) > phi_star(c2) + tol`.
  - `dgm_er_core_size(k: int, p: float, z: float) -> float` (DGM eqs. 1 and 4 for an ER graph: the lowest root R of `R = 1 − p + p·Q(k−1, z(1−R))`, iterated from R = 0, where `Q` = `scipy.special.gammaincc`; returns `p·(1 − Q(k, z(1−R)))`, or 0 if R > 1 − 1e-9; for k = 1 returns p).
  - `dgm_er_Qc(k: int, z: float) -> float`: the largest removal fraction Q = 1 − p with core size > 1e-6 (bisection, 50 iterations).
